# Ai-tools
# 🚀 AI Tools Directory

A modern, responsive, single-file HTML application for browsing AI tools by category.

This project is built using **pure HTML, CSS, and JavaScript** with **no external libraries or frameworks**, making it lightweight, portable, and easy to customize.

---

## ✨ Features

- 🔍 Real-time search
- 🗂️ Category filtering
- 🎨 Color-coded categories
- 🏷️ Category badges
- ⭐ Difficulty rating (1–5 stars)
- 🌐 Direct website links
- 📱 Fully responsive layout
- ⚡ Fast client-side rendering
- 📊 Priority-based sorting
- 🎯 Single HTML file (no dependencies)

## 📈 Data Structure

Each tool is stored as a JavaScript object.

Example

```javascript
{
  Tool: "ChatGPT",
  Category: "Content",
  Difficulty: 1,
  Priority: 5,
  Role: "Content Writer",
  "Official Link": "https://chat.openai.com"
}
```

The UI is generated dynamically from this dataset.
